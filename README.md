# AI Knowledge Retrieval & RAG Assistant

An end-to-end intelligent document query application that ingests unstructured technical documents, vectorizes content, and powers context-aware conversational Q&A with real-time streaming responses.

## Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Python (FastAPI), Server-Sent Events (SSE)
- AI / LLM: LangChain, ChromaDB, Gemini API

## Key Features
- Semantic Chunking: Vector storage and semantic search using ChromaDB and LangChain.
- Token Streaming: Real-time UI updates via Server-Sent Events.
- Prompt Engineering: Structured JSON schema enforcement to ensure predictable API outputs.
